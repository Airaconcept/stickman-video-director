# adapted/ —— 火柴人 Skill 提示词适配层

把本仓库原 Skill（`skills/directing-stickman-videos/`，原为 Gemini Omni Flash 设计）的提示词体系，适配到我方生视频工具 `media.generate_video`，并补上人物一致性机制。

**只新增，不覆盖**：原目录和原模板（谷歌版）保持原样；本目录是独立的适配层。

## 文件说明

| 文件 | 内容 |
|---|---|
| `prompt-template.md` | 适配后的单镜提示词模板（6 段自然语言），含与原合同的逐段对照表、画风锚点速查 |
| `character-card.md` | 角色卡模板 + 人物一致性三层机制（文本锁 / 定妆图锚点 / 逐镜验收），含各画风预置「逐字复用块」 |
| `test-results/` | 实测产物（定妆图）和本文件的实测记录 |

## 本次适配改了什么（与原版的差异）

1. **删除输出规格串**：原版每镜带 `720p、24 FPS、同步音频` 等 Flow 界面参数；我方工具不接受参数，规格由工具管线决定，写进提示词只会变噪音。
2. **删除台词 / 声线块 / BGM 续接三段**：原版依赖 Omni Flash 原生配音和音频生成。适配层走**无声画面**路线：配音、字幕、合成是后期独立流程（本次不碰），提示词里也不再出现任何台词——画面内禁止文字和对白框。
3. **计时节拍改自然语言**：`[0–3s]` 等方括号格式标记改为「开头 / 接着 / 最后」；三段时序逻辑（建立→发展→收束）完整保留。
4. **运镜术语翻译**：`camera push/pull/orbit`、Flow 专属措辞（如大喊式的 `STRICTLY MINIMALIST`）全部改成通用自然语言描述。
5. **角色锁强化**：原版 Style 2 后续镜用的是 "The same…figure in a bright red beanie…" 的代称+省略号写法；适配层**禁用代称**，每一镜都粘贴角色卡的完整「逐字复用块」。这是跨模型时一致性最容易翻车的地方，必须写满。
6. **新增 image 输入方案**：我方工具支持给一张静态图让它动起来（谷歌 Flow 流程里没有这一步的等价物）。据此设计了定妆图流程：先按角色卡生一张定妆图给用户确认，之后每镜把定妆图随提示词一起传入，把一致性从"文字描述"升级为"图文双锁"。详见 `character-card.md` 第 2 层。

保留不变的原版经验：色板用普通词（禁用 hex/RGB，模型会把代码画进画面）；强调色全片最多 3 种；动作必须是具体身体动作（扯断、跃起、画线），不用抽象形态变形（会抖帧）；画面无文字是铁律。

## 怎么用（工作流）

1. 拿到文案，先选画风（不锁死，按文案情绪在画风库里挑）。
2. 按 `character-card.md` 模板给每个角色建卡，冻结「逐字复用块」。
3. （推荐）按定妆图模板生成定妆图，用户确认后冻结。
4. 把文案拆成镜头，每镜按 `prompt-template.md` 的 6 段模板写提示词：——其中段粘贴逐字复用块、一字不改。
5. 每镜调用 `media.generate_video`（有定妆图时随附 image 输入）。
6. 逐镜按 `character-card.md` 的验收清单检查，不合格改提示词重出，再进入拼接。

## 实测记录（2026-10-20）

### 视频生成：工具当前不可用（区域限制）
- 用适配模板写了两条 Style 1 Dark 测试镜（「内耗」主题：镜头 1 紫色思绪线团压迫、镜头 2 扯断金线迈步），调用 `media.generate_video`。
- 两次均返回 403：**视频生成对本账号所在国家/地区不可用，属长期限制，非临时故障**。
- 结论：适配模板已就绪，但当前工具链暂时无法产出视频；不是模板问题。账号侧限制解除后，按上面工作流直接可用。

### 定妆图验证：通过
- 改用 `media.generate_image` 按角色卡模板生成一张 Style 1 Dark 定妆图（`test-results/media-generation-stickman-test-character-sheet-0-f69394bd-44eb-4101-a0d5-e63df02bc7bb.png`）。
- 验收观察：纯黑背景、白色单线、空心圆头、无脸无填充、恰好两臂两腿、线宽均匀；高饱和紫色光点位于头顶右上方且只有这一处彩色；画面无任何文字/水印；竖版 9:16 构图正确。
- 小瑕疵：手臂线条偏长下垂、腿偏长，头身比略瘦高，但在火柴人画法语法内，可接受；如需调整在角色卡里加一句「比例适中、四肢长度与躯干相当」即可。
- 结论：角色卡的「逐字复用块」和画风锚点对我方生图工具是有效的；同一套文本锁迁移到视频工具的逻辑成立（视频侧待工具体系恢复后复验）。

### 备选路线（用户此前已认可的方向）
视频工具受限期间，可先走「生图路线」：用同套角色卡+模板逐镜生图，做成图文帖发抖音/TikTok——用户 2026-10-19 已表态这种用法可行。
