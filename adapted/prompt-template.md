# 适配后的镜头提示词模板

目标工具：`media.generate_video`（我方生视频工具）。

工具的输入形态：按顺序传 text/image 条目，内部的子代理自己把短提示词扩展成完整细节。**所以本模板要求：自包含、自然语言、不要任何模型专属的规格串和格式标记。**

## 与原版的对应关系

原 Skill（skills/directing-stickman-videos/references/omni-flash-prompt-contract.md）的 12 段结构中，适配版保留 8 段、删除 4 段、改写 1 段：

| 原版段落 | 适配版处理 | 原因 |
|---|---|---|
| 输出规格（约 10 秒、720p、24FPS、同步音频） | 删除 | 我方工具不接受这些参数，时长/分辨率由工具管线决定 |
| 环境与背景定义 | 保留 → | —— |
| 角色锁（逐字重复锚点） | 保留并强化 → | 角色卡逐字复用，见 character-card.md；禁用"同一角色"代称 |
| 色板（普通颜色词） | 保留 → | 禁用 hex/RGB 写法不变（模型会把代码字面画出来） |
| 构图策略 | 合并进 | 一句话即可，不用单独段 |
| 首帧状态 | 保留 → 前半 | —— |
| [0–3s]/[3–7s]/[7–10s] 计时节拍 | 改写 → | `[0–3s]` 这类方括号标记是给人读的契约格式，改为"开头/接着/最后"自然语言；**时序逻辑必须保留**（建立→发展→收束），因为镜头要有节奏感 |
| 英文台词引号块 | 删除 | 配音后期统一做（本轮不碰）；画面内也不许出现对白 |
| 完整声线块 | 删除 | 同上；不让模型配音 |
| BGM/SFX 续接 | 删除 | 本轮不碰音频；且我方视频工具不合成音频轨 |
| 末帧过渡状态 | 保留 → 后半 | —— |
| 负面约束 | 保留并强化 → | 模型专属措辞（如 "STRICTLY MINIMALIST" 大喊式写法）改为自然语言禁令 |

## 单镜提示词模板

以下 6 段按顺序拼成一条提示词。所有段都是一句话到几句话的自然语言。

```text
<画幅：如"竖版 9:16，适合手机全屏">。

<从画风库粘贴该画风的锚点原文，如：
Style 1 Dark：纯黑背景，二维极简白色线条动画，平滑、干净的线条风。>

<从 character-card.md 粘贴该角色的「逐字复用块」，一字不改。>

<本镜的场景和背景，一句话；把构图要求带进来，如：
纯黑空背景，人物站在画面中央偏下，右侧留白。>

<强调色用普通词，如：高饱和紫色、温暖金色；并说明彩色只出现在道具和图形上，人物本体不变色。>

开头：<建立：人物从哪里出现/在做什么，承接首帧>。
接着：<发展：1–2 个具体身体动作推进剧情，如"扯断""跃起""画线"，不要抽象变形（如楼梯融化成钟表）>。
最后：<收束：高潮动作，并停在一个下一镜能承接的状态>。

首帧：<上一镜末帧是什么状态>。末帧：<本镜结束时的状态，给下一镜用>。

画面中不要出现任何文字、字母、数字、字幕、对话框、水印和界面元素；
不要写实、不要 3D 人物、不要多余的胳膊和腿、不要身体变形、线条粗细保持均匀。
```

### 模板使用说明

1. **运镜词**：原版的 `camera push/pull/pan/orbit` 等 Flow 术语全部翻译成自然语言——"镜头缓慢推近""横移跟随人物""镜头拉远露出全景"。我方工具不解析参数式运镜指令。
2. **无声原则**：提示词里绝不出现台词、旁白、配音要求。视频工具产出的是无声画面；配音/字幕是后期流程的事。
3. **单镜一事**：一镜只讲一个动作转折。10 秒 clip 模板里"三段节拍"在适配版里压缩成"开头/接着/最后"三个短句即可，工具内部会自己铺细节。
4. **续接链**：做多镜时，每个镜的段要和前后镜对上——末帧写的状态必须就是下一镜首帧写的状态。断了链，拼出来就跳帧。
5. **色板守恒**：一个视频最多 3 种强调色，普通词命名，全片统一；不要在半路引入新颜色。
6. **无文字是铁律**：中英文字、数字、符号都不能出现在画面里。字幕、标题全部后期叠加。

## 画风锚点速查（从 style-catalog.md 提炼，可直接粘贴进）

- **Style 1 Dark**：纯黑背景，二维极简白色线条动画，平滑、干净的线条风。
- **Style 1 Light**：纯白背景，二维极简黑色线条动画，画面扁平干净，没有纹理、渐变和立体感。
- **Style 2A 科技风**：明亮的白色工作室空间，地面有淡淡的浅灰透视网格，高调布光，画面简洁留白，有青蓝色半透明玻璃 UI 元素。
- **Style 2B 故事风**：全彩电影感叙事环境，体积光和柔和景深，氛围感强；人物保持二维火柴人画风不变成 3D。
- **Style 3 史前风**：粗犷手绘二维黑线条，白色填充圆头，土黄色史前场景，可带纸张质感和暖火光。
- **Style 4 治愈风**：全彩二维卡通世界，温柔的氛围光，电影感构图；人物是白色填充头+深色火柴四肢的简约卡通角色。
