# 角色卡（Character Card）—— 人物一致性机制

本文件是 `adapted/` 适配层的核心。解决的问题：多镜视频里火柴人长相漂移（头变大、比例变、标志物丢失、多手多脚）。

## 一致性三层机制

### 第 1 层：文本锁（默认，必用）

- 每条视频开拍前，先按下面的模板定一份**角色卡**，其中「逐字复用块」是定稿文本。
- 写每一条镜头提示词时，把「逐字复用块」**一字不差**地粘贴进提示词的段。
- 禁止用「同一个火柴人」「延续上一镜角色」这类代称代替完整描述——代称等于没锁。
- 角色卡定稿后，改任何一处（标志物、配色、比例）都要同步改全部镜头，不能只改一镜。

### 第 2 层：定妆图锚点（推荐，长片/重要项目用）

`media.generate_video` 支持 image 输入（给一张静态图让它动起来），所以可以先定妆再开拍：

1. 用 `media.generate_image` 按角色卡生成一张**定妆图**：角色全身、标准站姿、画风背景、标志物齐全。
2. 定妆图给用户确认；不通过就改角色卡再生成，通过后冻结。
3. 后续每个镜头调用 `media.generate_video` 时，把定妆图作为 image 输入随提示词一起传，提示词开头写：「以输入图片中的火柴人角色为准开始动画」。
4. 更强的衔接做法：把上一镜的末帧截图作为下一镜的 image 输入（首尾帧接力），镜头之间的人物和位置最稳。

注意：image 输入是「让这张图动起来」，适合单场景延续；跨场景大跳切时优先用定妆图，不要用上一镜末帧（会把旧场景带进来）。

### 第 3 层：逐镜验收（必做）

每生成一镜，逐项检查，不合格就改提示词重出，不要带病往下拼：

- [] 头型与头身比例和角色卡一致，没有突然变大/变形
- [] 标志物在位（帽子/衣服/配饰没丢、没变色）
- [] 恰好两条胳膊两条腿；抬起的肢体没有在原位留下「残影肢」
- [] 线条粗细全程均匀，没有忽粗忽细
- [] 本体配色没被强调色污染（强调色只在道具/图形上）
- [] 画面里没有文字、字母、数字、字幕、水印
- [] 没有多出未计划的角色

> 经验（原仓库实测记录）：文本锁能显著减少漂移，但不是保证；手脚端点和跨镜线宽仍可能有小差异，必须靠验收兜底。

## 角色卡模板

每个角色一份。单角色短视频只填主角即可；多角色时每人一份，且要求彼此有**至少两个非颜色差异点**（如身高差+标志物不同），避免模型把两人画混。

```text
角色卡：<角色名/代号>
- 画风：<Style 1 Dark / Style 1 Light / Style 2 红帽 / Style 3 史前 / Style 4 治愈>
- 头部：<空心圆头无脸 / 空心圆头+简单线条表情 / 白色填充圆头+简单五官…>
- 身体：<单线无填充 / 瘦长白填充躯干…>，头身比例稳定
- 四肢：单线，恰好两臂两腿，线条粗细均匀
- 本体配色：<白色线条（黑底）/ 黑色线条（白底）/ 深色线条+白色填充…>
- 标志物：<如：亮红色毛线帽（圆顶、无球）+ 黄色 T 恤；或：无>
- 表情规则：<全程无表情 / 仅简单线条表情，不画瞳孔和写实五官>
- 禁忌：<按画风列：不填充身体、不加头发、不加多余衣物…>

逐字复用块（粘贴进每镜提示词，一字不改）：
「<一段完整、自包含的角色描述，见下方各画风预置块>」
```

## 各画风预置「逐字复用块」

直接取用、按画风二选一后冻结。改任何字都要全片同步。

### Style 1 Dark（黑底白线）

```text
同一个极简火柴人：空心圆头，没有脸、没有眼睛嘴巴、没有头发、没有衣服、没有填充的身体；比例稳定，四肢是连贯的单线，线条粗细均匀；恰好两条胳膊和两条腿，每条肢体只保留当前姿势（抬起的手臂会替换掉放下的那条线，绝不在原位留下第二条手臂）；人物本体始终是白色线条，彩色只出现在道具和图形效果上。
```

（需要表情时，把「没有脸、没有眼睛嘴巴」替换为「只有偶尔的简单线条表情，不画精细五官」，其余不动。）

### Style 1 Light（白底黑线）

```text
同一个极简火柴人：空心圆头，没有脸、没有眼睛嘴巴、没有头发、没有衣服、没有填充的身体；比例稳定，四肢是连贯的单线，线条粗细均匀；恰好两条胳膊和两条腿，每条肢体只保留当前姿势（抬起的手臂会替换掉放下的那条线，绝不在原位留下第二条手臂）；人物本体始终是黑色线条，彩色只出现在道具和图形效果上。
```

### Style 2 红帽 Zeke（彩色）

首镜：
```text
一个极简二维动画火柴人，戴亮红色毛线帽（光滑圆顶、没有绒球），穿黄色 T 恤，黑色单线四肢，穿短裤。线条简洁干净，色彩鲜明，平滑的二维动画风格。头部不画精细眼睛和瞳孔。
```

后续镜（原 Skill 用的是省略号代称——在适配层**禁用**这种写法，后续镜也粘贴首镜同一段完整描述，只把场景和动作换掉）。

### Style 4 治愈故事风

```text
一个极简二维卡通主角：白色填充的圆头，两个小小的深色椭圆眼睛，简单的眉毛线条和短弧线嘴巴；躯干是瘦长的闭合形状，白色填充、深色描边；双臂双腿都是深色单线，粗细均匀，手是小小的深色圆点，脚是短短的深色圆头线条；没有头发和衣物配饰；头身比例、白色填充和描边粗细在每一镜保持不变；恰好两条胳膊两条腿，动起来的肢体替换旧姿势、不留残影；表情只改变简单的面部线条，绝不改变头型和角色设计。
```

### Style 3 史前手绘风

该画风没有统一主角，按故事选角：每个角色在角色卡里写清头身比例、发型、眉眼特征、兽皮服装轮廓和一件标志配饰，逐字复用块 = 该角色卡全文。其余规则（白色填充头、黑色火柴四肢、土黄场景）归段管理，不写进角色块。

## 定妆图提示词模板（第 2 层用）

```text
<画幅说明，如：竖版 9:16>。<画风锚点原文>。画面中央站着<逐字复用块>。标准站姿，双臂自然下垂，正面朝向镜头，<画风背景>。画面中不出现任何文字、字母、数字和水印。
```
